# Aurora 界面设计与演进记录

这份文档记录界面设计的**决定与理由**，以及哪些做法被明确否掉。它存在的意义是：这套
界面经过多轮返工，返工的原因大多是同一个——把「在线曲库」和「本地文件」当成了对等的
两半。把结论写下来，是为了不再走回去。

## 一、基础：色彩不由界面决定

`tokens.css` 的核心概念是**外壳不自带颜色**：界面上每一个彩色值都在运行时由「正在播放
的那首歌的封面」提取得到（`src/stage/colors.ts`）。没有播放时 `--accent` 是扁平钢灰
`#7d8899`，整个界面是单色的。

这一条决定了界面**不能**靠固定品牌色来建立识别度，识别度来自「随音乐变化的那一层」。
所以任何「给界面选一个主色」的提议都与这个设计冲突。

> 一个实际教训：审阅截图时很容易把封面提取出来的颜色（例如某张封面的荧光绿）误当成
> 界面主题色，进而得出「深色底 + 荧光绿强调」这种通用套路的结论。**那是动态值，不是
> 设计选择**。判断配色先看 `tokens.css`，不要看截图。

## 二、几何与字体：已有约定，不要再发明

- **三个圆角按角色分配**：`--r-control: 4px`（按钮、输入框）、`--r-panel: 8px`（面板、
  卡片容器）、`--r-art: 12px`（封面图）。不使用「所有东西同一个圆角」的做法。
- **字号五档**：`--fs-display 26 / title 15 / body 13.5 / meta 12 / micro 11`。
- **字体**：`Segoe UI Variable Text`（正文）与 `Display`（标题），随 Windows 11 提供，
  中文回退到微软雅黑 UI；不引入 Web 字体。
- **分隔符约定**：元信息用中点 `·` 连接并带空格（`12 首 · 45 分`），这句式在
  `AlbumDetail.tsx` 里已存在。补充说明用中文逗号。
- **区块小标题**（`.rail__heading` / `.accounts__heading`）：11px、字重 500、
  `--text-low`、句子大小写。**不使用全大写 + 字距（tracked-out ALL-CAPS）**——类型系统
  里没有这种标签，加进去会立刻显出模板感。
- **粗细层级**用颜色深浅表达（`--text-hi / mid / low` 三档），不靠加粗堆叠。

## 三、结构：在线是主体，本地是补充

主流流媒体播放器的组织方式是**在线曲库为主、本地文件为辅**。Aurora 曾经反过来：侧栏里
本地有四个平级入口（专辑/艺术家/歌曲/文件夹），在线只有「网易云音乐」一行、所有内容都
藏在页内。这被指出为「本地分那么多，网易云怎么就一个」。

2026-11 的第二次重构把这条原则推到了底：一级导航只按**意图**分，平台与本地文件都退化成
「音乐库」里的来源标签页（参照 Rhine / QueMusic / Mineradio 的交互分级）。

```
发现         各平台的新歌速递、推荐歌单、精品歌单（未登录也有内容）
音乐库       来源标签页：本机 / 网易云 / QQ 音乐；本机再分 歌曲/专辑/艺术家/歌单/文件夹
设置         01 播放与音质 / 02 外观与桌面 / 03 快捷键 / 04 更新与关于
```

搜索不占导航：全应用只有一个搜索框，常驻标题栏（`Ctrl K`）。搜索是动作，不是目的地。

**账号也不占导航**：它是侧栏最底下那张头像点进去的一页（`src/views/AccountView.tsx`）。
账号不是偏好——换档案、扫码登录随时会发生；放设置里等于把高频动作塞进低频页面。
头像本身显示当前档案的样子（自设头像 → 绑定的平台头像 → 名字首字），所以那一行
既是入口也是「现在是谁」的指示。

默认落地页是**发现**：第一次打开就有东西可听、可看，而不是一个空曲库。

**不要**再给「网易云」造一个独立页面外壳（自带标题、自带 268px 侧栏）。那正是「像两个
拼接的应用」的来源。在线内容与本地内容共用同一套页面骨架和同一个卡片组件
（`src/ui/ArtCard.tsx`）。

## 四、页面级约定

- **一页一个标题**：由外壳（`App.tsx` 的 `main__header`）打印，页面内部不重复打印标题。
- **曲库操作只在曲库页面出现**：「重新扫描」「添加文件夹」只在显示本地文件的页面
  （`LIBRARY_VIEWS`）出现。任何新页面默认不显示它们。
- **页内不要再造侧栏**。

## 五、账号模型：网易云账号绑定到档案

档案（profile）是完整身份：本机曲库、本地歌单、**以及在线账号**。网易云会话按档案分文件
存放（`userData/netease-session.<档案ID>.bin`，safeStorage 加密），切换档案即切换在线
账号。账号页显示每个档案绑定的在线账号，并可单独解绑。

不要退回「全机共用一个在线会话」——那会让每个档案看到同一套在线歌单，与档案的语义矛盾。
